Portfolio

Project: Kleano Dentistry Intelligence

Problem: The network-wide no-show rate looked normal, hiding clinic-level revenue loss across 11 dental clinics (NY/MA/CT).

What I built: An end-to-end pipeline on a 3M+ row synthetic dataset: dbt/SQL modeling in PostgreSQL, Python EDA, and machine learning, designed from scratch rather than querying an existing warehouse.

Tools: Python, SQL, dbt, PostgreSQL, Seaborn, machine learning

Result: Across 900,000+ appointments, no-shows cost about $39,843/month per clinic on average. One clinic ran 14.9 points above the network average, pointing to roughly $265,613/month in recoverable revenue.

Link: GitHub repo

Project: NBA Automated Data Pipeline & Analytics Dashboard

Problem: Raw NBA API data is nested and inconsistent, and keeping it current requires manual pulls, which makes player and game analysis slow.

What I built: A Python pipeline that extracts game data, transforms it into analytics-ready datasets, and stores it in Amazon S3. AWS Lambda runs the ingestion on a schedule for reliable, automated updates. The S3 data layer feeds a dashboard of player and game-result metrics.

Tools: Python, AWS Lambda, Amazon S3, [add dashboard tool and any others]

Result: A fully automated, always-current data layer powering a per-player, per-game metrics dashboard, with no manual data pulls.

Next step: Add machine learning models to predict game outcomes and player performance, built on the data already in S3.

Links: GitHub repo | Live dashboard

Project: Loan Performance & Risk Analytics

Problem: Raw government loan approval data had inconsistent text fields, making it hard to compare exposure across lenders, states, and fiscal years.

What I built: A MySQL pipeline that cleans, normalizes, and optimizes the data into query-ready relational tables, then engineers exposure, market share, and concentration metrics with advanced SQL.

Tools: MySQL, SQL, Power BI

Result: An interactive Power BI dashboard with dynamic rankings and percentage-of-total analytics, publicly accessible.

Links: GitHub repo | Live dashboard
